| البند | المواصفة |

## 4. طرق الإنتاج

### أ) تسجيل استوديو بمعلق محترف (موصى به — أعلى جودة)
1. أرسل للمعلق هذا الملف (الجدول + النص المشكول).
2. اطلب ملفاً مستقلاً لكل سطر باسم المعرّف: `v01.wav` … `v18.wav`.
3. ضع الملفات في `public/audio/vo/final/`.
4. نفّذ:
   ```bash
   npm run retime        # يقيس مدد التسجيل ويعيد بناء الخط الزمني والموسيقى
   npm run render:final  # يخرج MP4 بالتعليق الحقيقي + خفض تلقائي للموسيقى
   ```

### ب) صوت ذكاء اصطناعي احترافي (ElevenLabs / Azure Neural TTS / Google)
- ElevenLabs: نموذج *Multilingual v2* أو أحدث، صوت عربي رجالي عميق، Stability ≈ 35–45٪، Style ≈ 30–40٪.
- Azure: صوت `ar-SA-HamedNeural` أو `ar-EG-ShakirNeural` مع SSML (`<prosody rate="-5%">` للرقم، `<emphasis>` للاسم).
- الصق النص **المشكول** من القسم 3 سطراً سطراً، صدّر كل سطر `vXX.wav` ثم اتبع الخطوات 3–4 أعلاه.

### ج) المسار الإرشادي (المتوفر حالياً في المشروع)
- `public/audio/vo/guide/*.wav` — صوت إرشادي آلي (espeak-ng + MBROLA) مولَّد داخل المشروع لضبط التوقيت فقط.
  **ليس بجودة البث** ولا يُنشر. معاينة: `npm run render:guide`.

## 5. المكساج
- الموسيقى تنخفض تلقائياً ≈ −10 dB أثناء كل سطر (`src/components/AudioLayer.tsx`).
- المؤثرات (Whoosh / Impact / Hit / Riser / Shimmer / Ding / Tick) مُزامنة مع الانتقالات وظهور العناصر.
- الهدف النهائي للمنصات: ‎−14 LUFS‎ متكامل، ذروة ‎−1 dBTP‎.
